Reports Kotlin usages of APIs marked with @RequiresApi when they are not protected by a matching version guard.

The inspection recognizes direct version guards such as:

  • if (Constants.is(1211)) { ... }
  • if (Constants.MINECRAFT_VERSION == 1211) { ... }

It also accepts enclosing declarations annotated with @RequiresApi and suppresses diagnostics when the API is available on every configured multiversion target.
